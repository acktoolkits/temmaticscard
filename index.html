      Desain kartu

      Panduan file

      • Format SVG dengan rasio 1,586 : 1, contoh viewBox 0 0 856 540.
      • Hanya latar. Pada tata letak Standar dan Platinum, logo dan label tier ikut digambar di SVG. Aplikasi menaruh nama, nomor kartu, tanggal bergabung, dan QR di zona yang ditandai. Teko dan dripper di sisi belakang dari sistem.
      • Sisi belakang pakai latar gelap atau biru, supaya teko, filter, dan server berwarna krem tetap terbaca.
      • Maksimal 400 KB per file. Hindari teks yang belum diubah jadi outline.

        Halaman pelanggan tidak menampilkan tautan staf. Tiga cara membukanya:

        • Perangkat staf (paling mudah): centang "Ingat perangkat ini sebagai perangkat staf" saat masuk. Berikutnya aplikasi langsung membuka layar PIN.
        • Kode di kolom nomor: di layar masuk pelanggan ketik *1# untuk Kasir atau *2# untuk Manajemen, lalu tekan Masuk.
        • Ketuk logo Temma 5 kali di layar masuk pelanggan.
